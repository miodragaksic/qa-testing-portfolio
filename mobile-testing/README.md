# Mobile Application Testing

This section will contain Android/mobile QA work performed on real test targets.

Planned coverage:
- installation/update
- permissions
- portrait/landscape
- background/foreground
- network interruption and Wi-Fi/mobile-data changes
- validation and negative testing
- crash/freeze reproduction
- device/resolution checks
- ADB/logcat evidence as technical skills develop

No fabricated test results are included. Test cases and reports will be added after execution.
