**Manual QA · Web Testing · Mobile Application Testing · AI Application Testing**

This repository documents practical software testing work: test planning, exploratory and functional testing, usability testing, negative testing, test case design, bug reporting, severity assessment, and evidence-based QA conclusions.

## QA approach

I document **what I tested, exact steps, expected result, actual result, evidence, and status**. When evidence is insufficient, I mark the result as **Blocked** or **Needs clarification** instead of presenting an assumption as a confirmed defect.
